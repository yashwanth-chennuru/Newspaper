Perplexity appears to test OpenRouter access for Computer

An unfinished integration could let Computer users supply models through OpenRouter instead of relying only on platform credits.

TestingCatalog reports that Perplexity is experimenting with an OpenRouter connection inside Perplexity Computer. The reported wiring is not yet functional publicly, making this an internal-product signal rather than a released feature.

The proposed connection would let a subscriber link an OpenRouter account and potentially route the computer agent through models from OpenRouter’s catalogue. In practice, that could give a user more control over the trade-off between model quality, cost and speed.

The appeal is especially clear for multi-step agent work. Computer reportedly coordinates several models across local and remote environments, and those workflows can consume platform credits quickly.

An account-level model connection could reduce that cost for some users and make experimentation easier. It could also change Perplexity Computer from a tightly metered service into a more flexible orchestration layer.

There are unresolved questions: which models would be supported, how keys and data would be handled, how failures would be managed, and whether the eventual feature would be available beyond a narrow tier. None has been answered by Perplexity publicly.
