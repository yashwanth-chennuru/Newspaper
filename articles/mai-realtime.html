Microsoft tests a native, real-time voice model

A reported full-duplex MAI model could bring speech-to-speech capability into Microsoft’s own model stack.

An early-access listing in Microsoft’s MAI Playground points to a model called MAI Realtime, according to TestingCatalog. The listing is not a public product announcement, so its name, availability and final feature set should all be treated as provisional.

The reported capability is full-duplex conversation: the model can hear and speak at once instead of waiting for a user to finish a turn. TestingCatalog describes low-latency responses, interruption handling and configurable turn-taking, two mechanics that strongly shape whether voice interaction feels natural.

The report says MAI Realtime supports 17 languages and currently offers two voices. It also describes two listener approaches: a Switchboard mode using an MAI-Ears endpointer and a deterministic alternative combining silence detection with a Whisper semantic endpointer.

Microsoft’s existing in-house voice models are described as one-way components—MAI-Voice for synthesis and MAI-Transcribe for recognition—while Azure Speech’s Voice Live API uses GPT-Realtime for speech-to-speech. A native realtime model would potentially close that gap.

The clearest implication is architectural rather than consumer-facing: Microsoft could control more of the voice stack used by Copilot, Teams or Foundry. But there is no announced release date, and early playground evidence is not confirmation of a launch.
